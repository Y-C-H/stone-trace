돌에 새겨진 흔적

「돌에 새겨진 흔적」은 고인돌의 3D 스캔 데이터와 성혈(바위구멍) 측정 자료를 활용한 디지털 문화유산 전시 웹페이지입니다.

관람객은 고인돌을 직접 관찰하고, 돌에 새겨진 성혈의 형태와 위치를 살펴보며, 고대 사람들이 이 흔적에 부여했을 의미를 탐색할 수 있습니다.

또한 성혈의 위치·크기·깊이를 바탕으로 구성한 밤하늘을 감상하며, 문화유산의 새로운 해석 가능성을 경험할 수 있습니다.

로컬 실행 방법

웹페이지를 인터넷에 배포하지 않고 자신의 컴퓨터에서 실행하려면 아래 방법을 이용하십시오.

1. ZIP 압축을 해제하고 index.html이 있는 폴더를 엽니다.
2. 탐색기 주소창에 cmd를 입력하고 Enter를 누릅니다.
3. 명령 프롬프트에서 다음을 실행합니다.

   py -m http.server 8000

   (py를 사용할 수 없으면 python -m http.server 8000)

4. 브라우저에서 http://localhost:8000 에 접속합니다.
5. 서버 종료: 명령 프롬프트에서 Ctrl + C

※ Python이 설치되어 있어야 합니다.

※ index.html을 더블클릭(file://)하면 3D 파일 로딩이 차단될 수 있습니다.
